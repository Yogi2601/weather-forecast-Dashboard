================================================================================
WHAT GETS REFRESHED
================================================================================

For each saved location:
  - Gets latest ~365 days of historical weather
  - For each day:
    - Checks if record already exists
    - If missing: inserts new record
    - If exists: skips (no duplicates)

Records contain:
  - Date
  - Temperature (max, min)
  - Precipitation
  - Wind speed

Database table: weather_history
Unique constraint: (location_id, weather_date)

================================================================================
SCHEDULE DETAILS
================================================================================

Default: Daily at 2:00 AM
Location: Windows Task Scheduler
Task name: WeatherDashboard-DailyRefresh
Script: backend/refresh_weather.py

To change time:
  1. Edit backend/setup_scheduler.ps1 line 18
  2. Change $Time = "02:00" to desired time (24-hour format)
  3. Re-run: powershell -ExecutionPolicy Bypass -File setup_scheduler.ps1

Examples:
  "00:00" - Midnight
  "06:00" - 6 AM
  "12:00" - Noon
  "18:00" - 6 PM
  "23:00" - 11 PM
