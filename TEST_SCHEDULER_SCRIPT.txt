TROUBLESHOOTING
================================================================================

If you get "must be run as Administrator":
  - Right-click PowerShell
  - Select "Run as Administrator"
  - Try again

If you get "files not found":
  - Verify backend/.venv exists (Python virtual environment)
  - Verify backend/refresh_weather.py exists
  - Check file paths are correct

If task creation fails:
  - Check Windows Task Scheduler is accessible
  - Verify you have admin rights
  - Check weather_refresh.log for details
