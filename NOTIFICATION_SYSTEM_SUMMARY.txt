DATA STORAGE
================================================================================

localStorage Key: "weatherDashboard.notifications"

Notification Object Structure:
{
  id: number (timestamp + random),
  type: string (city_searched|rain_alert|temp_alert|api_error|location_added|location_removed|download_complete|refresh_complete),
  title: string (e.g., "City Searched"),
  message: string (e.g., "Now viewing weather for Paris."),
  timestamp: string (ISO 8601 format),
  read: boolean (false = unread, true = read)
}
